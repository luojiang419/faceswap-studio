## 开发与发布

魔搭仓库：[facefusion-workbench-updates](https://modelscope.cn/models/jiangjiang419/facefusion-workbench-updates)。客户端只包含公钥与匿名下载地址，发布凭据和签名私钥均不进入分发包。

签名私钥由 `scripts/release_modelscope.py --init-key` 首次生成，保存在被 Git 忽略的 `.update-private/signing-key`。后续发布必须复用此密钥，不得重新生成公钥替换客户端的信任关系。软件版本读取 `VERSION`；普通调试保持版本号，通过发布序号识别新构建。

```powershell
# 先完成 Flutter Windows/Web、启动器、独立更新器构建
./scripts/build_flutter_app.ps1
./scripts/build_launcher.ps1
./scripts/build_updater.ps1

# 创建签名更新包，输出不可变快照目录
python scripts/release_modelscope.py --notes "本次更新说明"

# 发布指定快照：先上传并匿名完整校验，再激活 public/latest.json
python scripts/release_modelscope.py --snapshot dist/modelscope/updates/<版本-发布序号> --publish

# 默认复用固定基础包，只生成新安装器并引用签名应用包
$releaseId = (Get-Content update-config.json -Raw | ConvertFrom-Json).releaseId
$installerOutput = "dist/modelscope/installer-$releaseId"
python scripts/build_lightweight.py --output $installerOutput
python scripts/build_lightweight.py --output $installerOutput --publish
```

默认发布使用 `installer/runtime-base.json` 固定基础包指针：Python、依赖、FFmpeg 和模型只在首次或内容变化时上传，普通代码修复只构建应用包和安装器。安装器分别校验基础包与签名应用包的固定哈希，再组合安装；已有用户仅修复应用文件时只下载应用包，不下载数 GiB 的基础包。发布前检查远端基础包已存在，缺失或哈希不一致直接失败，绝不自动重传大包。

首次指定基础包时使用 `--base <已发布基准目录>`，随后自动缓存或按 SHA-256 获取约 3.5 MiB 的基础描述。基础包本身不复制、不重新压缩、不重新上传；安装器和应用包同内容也直接复用远端资源。

更换 Python 依赖或常用模型时，先刷新离线 staging，显式使用 `--full-runtime` 生成、验证并发布一次新基础包，然后用 `--base` 更新指针。构建器检查 `requirements.txt` 和常用模型定义，定义变化时拒绝继续套用旧基础包。所有资源使用不可变魔搭路径，相同远端路径存在不同内容时拒绝覆盖。

新的 Windows/Web 构建先进入签名应用包，再作为组合安装器的应用来源。只有显式重建基础包时才需要 `--windows-build-root` 映射另一个 Windows 构建；不会为普通界面或代码修复生成完整运行包。新的安装器 EXE 和 ZIP 使用新的输出目录，不重新编译已经发布的快照。

安装资源的发布证明记录在安装器输出目录的 `publication.json`，签名更新的证明位于对应快照目录的 `publication.json`。保留失败会话以便定位，不手动删除未完成事务的备份。

轻量安装器默认发布校验为远端 SHA-256、大小与匿名单字节访问，不再每次完整下载数 GiB 的运行包。远端同路径同内容直接复用；不同内容拒绝覆盖。只有明确需要完整下载验收时才在发布命令增加 `--full-readback`，证明中的 `anonymousFullVerified` 会如实记录是否执行。

仅调整安装器界面或安装维护逻辑时，直接引用同一应用快照，基础包与应用包都不重传：

```powershell
python scripts/build_lightweight.py --output "dist/modelscope/installer-new" --application-snapshot "dist/modelscope/updates/0.1.3-20261020090858"
python scripts/build_lightweight.py --output "dist/modelscope/installer-new" --publish
```

复用会验证原发行清单、应用签名、包 SHA-256、大小、公钥和文件记录，保留原基础包 URL 与实际应用序号。首次增加一份约 3.5 MiB 的基础描述后，后续只上传新的应用包、安装器与分发 ZIP；同内容资源不重传。应用内容变化不再触发基础运行包重建。

旧 GitHub 增量发布脚本保留作历史参考；当前客户端使用本页所述魔搭协议。
