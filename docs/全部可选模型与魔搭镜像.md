# 全部可选模型与魔搭镜像

当前镜像任务正在转存完整模型集合，完成审计后才会发布包含完整清单的软件更新。

## 覆盖范围

按当前 FaceFusion 3.9.0 源码的全部 `create_static_model_set('full')` 枚举，共 247 个内置模型选项，包含 97 个 ONNX 权重、157 个 DeepFaceLive DFM 权重，以及对应的 254 个 hash 文件，共 508 项资产、约 168.75 GiB。

覆盖检测、属性、关键点、遮罩、识别、内容分析、声音分离、年龄修改、背景移除、表情恢复、人脸编辑/增强/换脸、画面上色/增强、口型同步及内置 DeepFaceLive 模型。用户自行导入的 `custom` 私有模型不上传；演示图片、音频和视频不属于此模型清单。

每项保留上游仓库、固定提交、LFS SHA-256、原始 CRC、原模型选项及其许可元数据。权重沿用各自上游许可，不能把模型仓库中的全部内容理解为 Apache 授权。

## 使用方式

完整清单随签名应用更新分发，存放在 `facefusion/model_catalog.json`。选择缺失模型时才从魔搭下载；现有有效模型校验复用，首次安装继续只包含默认常用模型。

工作台启动的服务、预览和队列优先使用魔搭。新安装的默认下载源同样优先魔搭；独立 CLI 可通过 `--download-providers modelscope` 选择魔搭，也保留显式选择 `github`、`huggingface` 的兼容能力。系统/自定义代理设置仍控制实际网络连接。

下载使用固定大小和 SHA-256，支持断点、分段 CDN、截断恢复和空间预检；临时文件验证通过后原子替换。模型的原始 CRC 继续验证，采用分块读取，避免 DFM 预检一次性读入整个大文件。

## 维护与恢复

```powershell
# 在上游可正常直连时省略 --proxy；本机直连失败后可使用已配置的代理读取上游。
python scripts/modelscope_models.py prepare --proxy http://127.0.0.1:7890
python scripts/modelscope_models.py publish --workers 4 --proxy http://127.0.0.1:7890
# 全部完成后逐项审计，并发布不可变模型清单。
python scripts/modelscope_models.py audit
python scripts/modelscope_models.py publish-catalog
```

维护目录为 `build/modelscope-all-models`，不提交模型二进制或登录凭据：

- `plan.json`：来源、固定哈希、大小与目标路径。
- `proofs/*.json`：每项已完成的可恢复证明。
- `progress.json`：当前完成数量、容量及错误计数。
- `publication.json`：最终全量覆盖审计。
- `cache`：每个工作线程一个权重缓存；成功转存并核验后只清理本次生成的缓存文件，原 `.assets/models` 不删除。

脚本通过魔搭 SDK 确认全局已存在的相同 SHA 对象并复用其 LFS 引用，缺失对象才从上游下载、完整校验后上传。传输并行，仓库提交串行，避免提交锁冲突。恢复时优先处理已有缓存和已验证条目。

发布门禁比对当前源码、完整计划、508项证明、最终发布报告与客户端清单；未完成或任一证据不符时禁止上传完整清单。签名更新与新安装运行包都必须包含同一份清单。安装器可用 `scripts/build_lightweight.py --output <新目录> --refresh-from <已验证旧运行包>` 复用已有依赖；旧产物保留，新文件写入后逐项检查SHA-256。

所有 hash 文件完整匿名回读；权重校验上游 SHA/CRC、本地完整文件、服务端 SHA/大小及匿名首尾范围。客户端实际下载时再次验证整个权重 SHA-256。此审计不等同于逐个模型都执行了推理。
