# 安装、检查与修复

使用同一个 `易容 Studio 安装器.exe`。首次选择专用目录安装；再次运行时自动识别由本安装器管理的现有安装，并先进行只读检查。

检查内容包括程序文件、便携 Python、依赖、运行包内模型、图标与卸载程序，以及 Python 路径和实际依赖导入。正常时显示“一切正常，无需再次安装，开始创作吧”，可直接打开工作台；健康检查不关闭工作台，也不改写安装目录。

发现问题后，点击“开始修复”。安装器验证完整运行包后，只恢复缺失、损坏或与当前目标发布不一致的文件，随后再次检查。修复入口直接使用原生 .NET，即使目标 Python 已丢失，也不需要先修好旧 Python 才能恢复。

修复保留作品、人物数据、用户配置、已有 `facefusion.ini` 和运行包清单外的模型。程序版本或发布序号高于修复包时拒绝降级，应使用更新的安装器。

修复前请完成或取消生成任务。只有需要写入修复文件时才请求本目录工作台正常退出；队列仍有任务、状态无法确认或进程无法正常退出时，会停止修复并显示原因，不强杀任务。失败、取消或修复后的复检失败，均会回滚本次文件替换。旧更新事务可按可信完整运行包前向恢复，原事务日志和备份保留。

日志和备份位于 `%LOCALAPPDATA%/FaceSwapStudioMaintenance/sessions/`。检查失败会显示原因和日志位置，不会当作健康安装处理。无法识别安装身份的任意文件夹不会被自动接管；损坏的安装归属记录也不会被伪造为有效安装。

安装器本身约 1.4 MiB，首次安装或缺少修复缓存时需要从魔搭下载约 3.61 GiB 的完整运行包。首次安装保留至少 12 GiB 可用空间。若完整运行包与安装器放在同一目录，维护流程可直接校验并使用该包。

## 开发验收

- `python scripts/test_installer_maintenance.py`：维护、下载与安装集成回归。
- `python scripts/smoke_installer_maintenance.py <安装器输出目录>`：从正式运行包构建隔离维护夹具，使用正式 EXE 实测 Python 缺失、同长度程序损坏、模型校验文件损坏的恢复，以及个人数据保留和复检；不冒充首次安装桌面握手。
- `python scripts/render_installer_maintenance.py <bootstrap-manifest.json>`：通过安装器自身控件离屏渲染浅深维护界面，无桌面输入或屏幕捕获。

命令行诊断支持：

```powershell
& ".\易容 Studio 安装器.exe" --inspect-root "D:\Program Files\易容 Studio" --report "D:\检查报告.json"
& ".\易容 Studio 安装器.exe" --repair-root "D:\Program Files\易容 Studio" --report "D:\修复报告.json" --package "D:\易容-Studio-0.1.3-20261019081931-Runtime.zip"
```

报告必须位于目标安装目录之外。退出码 0 表示健康或已成功修复，2 表示只读检查发现问题，1 表示检查或修复失败。
