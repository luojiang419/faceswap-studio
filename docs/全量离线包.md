# 全量离线包

全量版使用现有原生安装器和独立更新器，安装器与完整资源 ZIP 一起分发。用户完整解压后双击 `易容 Studio 全量安装器.exe`，首次安装直接校验并展开相邻资源，不下载或在安装目录缓存完整 ZIP。再次运行同一安装器可检查和离线修复；修复时需保留相邻资源 ZIP。

## 包含范围

- 指定安装目录内的 Python、venv、NVIDIA CUDA/cuDNN 依赖、FFmpeg/FFprobe 与 `.assets/models` 全部模型；不带个人作品、人物照片、配置、任务记录、下载分片或缓存。
- 应用 Python 源码取当前项目；Windows 前端默认取指定安装目录的已验证部署，可用 `--windows-build-root` 显式指定其他完整构建。避免工作区旧部署覆盖用户当前使用的最新界面。
- VC++ 可分发 DLL 分别放入 Python、venv 可执行目录与 Flutter 可执行目录，源自 Visual Studio x64 CRT，不复制系统目录或重新安装全局运行库。
- `runtime-profile.json`、`requirements-runtime.lock.txt` 和 `included-models.json` 记录真实版本与模型 SHA。保留各组件原有许可文件。

## 显卡与运行时

使用同一套 CUDA 12.9 / cuDNN 9.23.1 / ONNX Runtime GPU 1.24.4；ORT 本身编译于 CUDA 12.8，同一 CUDA 12 主版本兼容。建议 NVIDIA Windows 驱动 576.57 或更新；不包含驱动，也不要求用户预装完整 CUDA Toolkit。

| 显卡 | 二进制依据 | 实机验证 |
|---|---|---|
| RTX 20 | ORT `sm_75` cubin，cuDNN 支持 Turing | 无对应设备 |
| RTX 30 | ORT `sm_86` cubin，cuDNN 支持 Ampere | 无对应设备 |
| RTX 40 | ORT `sm_89` cubin，cuDNN 支持 Ada | 本机 RTX 4070 Ti SUPER 验收结果见本次交付记录 |
| RTX 50 | ORT 200 个 `.target sm_90` PTX 向前兼容；cuDNN 含 `sm_120` | 无对应设备 |

50 系首次使用可能需要驱动即时编译 PTX；不能将官方兼容关系和二进制检查描述为 50 系实机验证。官方依据：[cuDNN 支持矩阵](https://docs.nvidia.com/deeplearning/cudnn/backend/v9.23.1/reference/support-matrix.html)、[CUDA 发行说明](https://docs.nvidia.com/cuda/archive/12.9.1/cuda-toolkit-release-notes/index.html)、[Blackwell PTX 兼容指南](https://docs.nvidia.com/cuda/blackwell-compatibility-guide/index.html)。

## 原版 WebUI 与其他模型

安装目录的 `启动原版WebUI.cmd` 使用内置 Python，默认打开 <http://127.0.0.1:7861>；端口占用可运行 `启动原版WebUI.cmd --port 7862`，关闭命令窗口后服务停止。也可从桌面工作台现有入口打开由 Bridge 管理的原版界面。

原版界面的模型选择继续调用 FaceFusion 的 `pre_check` 与统一下载器。静态清单涵盖全部内置选项：已镜像资源使用魔搭，74 个未镜像 DFM 使用固定原 Hugging Face 提交。外网资源自动读取环境或 Windows 系统代理；下载保留分片并进行 SHA-256/CRC 校验，完整有效的本地模型直接复用。原版入口移除继承环境中的 `NO_PROXY=*`，保留其他明确代理设置及本机地址绕过。其他模型仍需联网，私人自定义模型需用户自行提供。

## 构建与验证

在 Windows 项目根目录运行，输出目录必须不存在：

```powershell
.\.venv-win\Scripts\python.exe scripts/build_full_offline.py `
  --installation 'D:\Program Files\FaceSwapStudio' `
  --msvc-root 'C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Redist\MSVC\14.44.35112\x64\Microsoft.VC143.CRT' `
  --output 'dist\full-offline\新发行目录'
```

仅应用变化时可加 `--refresh-from <旧全量目录>`，复用相同已核验运行时和模型，保留旧候选，只增量替换应用。运行时版本、模型、原版入口或模型校验定义变化时重新全量构建。

`scripts/verify_full_offline.py --distribution <新发行目录>` 会创建唯一的 `build/full-offline-validation/中文安装/易容 Studio` 隔离测试安装，使用测试注册项与内部快捷方式，检查路径迁移、pip、实际 CUDA 卷积、随包模型推理、桌面首帧、核心 ready 和原版 WebUI HTTP。测试端口为 52782/17860/17861；测试服务退出后用实际安装器检查/修复，最后 `--phase remove` 验证卸载与个人作品保留。验收器使用与正式安装器一致的 .NET 4.8 和长路径规则。

完整验收后移除分发目录中的 `.NativeSmoke.exe`，再执行：

```powershell
.\.venv-win\Scripts\python.exe scripts/build_full_offline.py --output 'dist\full-offline\新发行目录' --distribute
```

分发前对资源 ZIP 内每个实际文件重新计算 SHA-256，并检查最终外层 ZIP 的 CRC，生成同名 `.zip.sha256`。不自动上传魔搭、改变公网更新入口或递增应用正式版本。
