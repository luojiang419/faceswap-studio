# 易容 Studio 品牌与发行规范

软件唯一对外名称为 **易容 Studio**。桌面与 Web 界面、窗口及托盘、快捷方式、系统应用列表、安装器、更新与卸载提示、当前说明及后续发行统一使用此名称。

- 用户启动入口：`易容 Studio.exe`。
- 安装器：`易容 Studio 安装器.exe`，分发压缩包：`易容-Studio-轻量安装器.zip`。
- 版本仍为 `0.1.3`，改名不递增正式版本；每次发行使用新的 `releaseId` 和独立输出目录。
- 为兼容已有作品、配置、安装与回滚，源码目录 `faceswap studio`、Dart 包名 `faceswap_studio`、FaceFusion 引擎名称、环境变量、互斥量、注册表内部键、维护缓存、运行包内部根目录及旧更新入口均为技术标识，继续保留。
- 历史任务记录和已发行旧资源保留原样；新增文案和发行资源只使用易容 Studio。
- 安装器清单记录运行包的实际应用序号与固定下载地址；安装器发行序号可独立推进。仅改安装器时复用已发布运行包，同一资源不重复上传。默认核对远端 SHA-256、大小和匿名单字节访问；完整回读仅在明确要求时使用 `--full-readback`。重新编译安装器不自动切换公网软件更新入口。

当前基准与旧版升级说明见 `docs/基准包与旧版升级.md`；本次构建与验收进度见 `开发任务/027-工作台外部拖拽与悬停动效.md`。
