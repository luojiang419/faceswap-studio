# 全屏教程录制与视频人物首帧

2026-10-24 验证，适用于本机 Windows 安装版和本次宣传片制作。

- **最大化被还原**：录制控制工具激活窗口时可能恢复普通尺寸，导致坐标偏移、录屏尺寸变化。使用侧栏“软件全屏”或 F11 的原生无边框模式；以 FFmpeg 截图尺寸和真实 Windows 集成测试确认 1920×1080。视频全屏退出时要保留应用全屏状态。
- **人物帧识别静默失败**：本机 OpenCV 5 已不提供 `CascadeClassifier`。复用安装目录现有 YOLOFace ONNX，在独立 CPU 会话中执行与引擎一致的 BGR/右下补黑/CHW/255 输入。无需下载模型，不改换脸进程的全局推理参数；按文件大小与修改时间缓存结果。本次原片定位 36 帧/1.44 秒，约 0.6 秒完成。
- **空镜影响演示**：教程另存裁切副本后导入，保留原素材；本次从 1.44 秒开始，副本第一帧直接出现人物。产品仍保留自动人物帧起播，未检出人脸时安全回到视频开头。
- **I/O 尾帧差一帧**：界面 O 点包含当前帧，引擎 end 为排除边界，提交时必须 +1。实测 I=53、O=183，实际任务参数 `[53,184)`，输出 131 帧/5.24 秒/25 fps。
- **录屏未写 moov**：不要依赖无标准输入的命令会话发送 q。`promo_capture.py` 使用有时限、fragmented MP4 和停止文件；下次录制可创建 `raw/<name>.stop`，由录屏父进程发送 q 并等待封装。结束后对使用片段重新封装并完整解码验证。
- **自动去静止误剪文字输入**：鼠标/单个文字变化可能低于整帧运动阈值。人工指定重要操作的保护片段，再检测长停顿；保存、输入和菜单打开动作必须保留。本次剪辑工程与原始事件时间均留在交付目录，可按相同素材重做。

入口：`scripts/promo_edit_fullscreen.py`；`promo_edit.py` 提供时间轴、音频、静止检测与视频读取公共函数。最终成片以新版全屏入口为准。
