# 安装版生成任务不要依赖开发脚本

表现：预览和服务启动正常，但添加队列或立即生成失败。日志显示 PowerShell 无法找到安装目录的 `scripts/facefusion.ps1`，退出码 64。

根因：任务创建和执行入口调用仓库开发脚本；精简安装包未包含该脚本及配套开发工具。核心服务本身使用 Python 引导启动，因此服务 ready 不能证明任务 CLI 可用。

解决：Bridge 任务 CLI 共用 `_resolve_facefusion_python_executable` 与 `_facefusion_bootstrap_code`，直接传递 `job-create`、`job-add-step`、`job-submit` 和 `job-run` 参数；保留工作目录、环境变量、ONNX DLL 预载及独立 jobs/temp 路径。不要以复制整套开发脚本作为安装版生成依赖。

验证：2026-10-20，使用真实安装版 Python/模型/FFmpeg 和新 Bridge 代码，在独立任务目录中完成立即生成与显式批量生成；两次 CUDA 4 帧短片均成功，原待办在显式批量启动前保持 queued。安装版原工作台草稿与参数保持一致。对应任务：`开发任务/029-立即生成与批量队列隔离.md`。
