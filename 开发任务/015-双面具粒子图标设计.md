## 目标与验收

用户要求两个面具叠加、粒子、透明底；进一步明确卡牌式重叠、扁平化，并指定采用启动器中人脸融合动画的样式。最终使用鼠尾草绿与暖铜色的线框人脸、三角网格、特征点与流动粒子，直接复用启动器绘图数据制作代码原生矢量及位图。此前 imagegen 的实体面具稿不作为交付。

设计包位于 `design/launcher-wireframe-icons/`。用户进一步确认“现在应用到软件，全面替换原来的图标”，授权替换现有品牌图标及重新构建部署。验收覆盖 Windows 窗口/托盘/快捷方式、根启动器/更新器、安装器图标和左上标志、桌面侧栏、Web 页签/应用图标/页头。保持透明底与正式版本；不覆盖历史安装包，不自动发布到外部服务。

## 安装检查修复一体化

用户已对照 VoxCPM 最新一体版确认“先补齐检查与修复，再生成新安装器”。原安装器仅有包内校验恢复及 Python 路径修正，没有完整维护入口。

实现选择：复用当前原生 .NET 安装器与可信完整运行包，用独立 C# 维护引擎执行扫描和文件恢复，不依赖待修复目录的 Python。健康检查不关闭工作台、不改写目标目录；发现问题后才进入有锁的修复事务。正常提示可直接创作，修复保留作品/配置/人物数据和清单外模型；修复前保护较新版本、阻止活动生成任务，修复后完整复检，失败回滚本次文件修改并保留日志。复用现有安装器主题及新图标。

新安装器使用独立发布序号和输出目录，保留版本 0.1.3 与旧安装包；对应新运行包必须实际可下载，不能交付指向未发布资源的 EXE。公网软件自动更新入口不随安装器发行切换。

- `installer/bootstrap/Maintenance.cs`：由原生 .NET 独立执行，扫描包内程序/运行时/模型 SHA-256；单独检查可迁移 pyvenv 路径、信任公钥和发布身份。正常不创建修复锁、不改写安装目录、不关闭工作台。先对照安装身份拒绝降级，再恢复坏文件；个人配置、作品与清单外模型不覆盖。Python 依赖损坏时仍能恢复文件，修复后再使用真实环境探测。
- 只有发现损坏后提供“开始修复”入口。修复首先下载并校验可信完整运行包，再正常关闭本目录工作台；队列仍有任务或进程无法正常退出时拒绝覆盖，不强杀用户任务。替换使用目标盘临时文件与外部备份，失败/取消/修复后复检失败均回滚。未完成更新可从完整包前向恢复，旧日志和备份保留；正常计划更新不判为损坏。
- 更新安装身份记录增加 releaseId，损坏配置可凭安装身份恢复。安装图标副本及卸载程序也纳入一致性恢复。日志/备份位于 `%LOCALAPPDATA%/FaceSwapStudioMaintenance/sessions/`。
- 维护命令行：安装器支持 `--inspect-root <目录> --report <外部JSON>` 和 `--repair-root <目录> --report <外部JSON> [--package <可信运行包>]`，用于隔离验收或故障诊断；报告必须在安装目录外。
