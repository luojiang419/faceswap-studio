## 实现

- 提取 worker 每处理一张图（含无脸/不可读跳过）原子写入进度 JSON；新增按请求 ID 隔离的只读进度端点，不持有人脸提取锁；严格校验 ID 防止路径穿越。完成、异常、超时均有终态，失败保留已处理计数。
- 原提取 POST 接口增加可选 `request_id`，旧调用不受影响；卡片每 500ms 读取实际完成数量，轮询不重叠、不倒退，页面销毁、完成和失败均停止；不同批次不串进度。
- 人脸格子在选图后立即显示点阵双脸、粒子流动交换、真实批次数量与进度条；存在无脸图片时额外区分有效/无效数量。提取失败提示且保留旧素材和预览。
- 视频格子覆盖读取信息期间的加载态；播放器初次打开期间继续显示同一套 SVG 胶片、悬浮与扫光动画。请求超时与已有上传流程保持一致，避免复杂素材仅因默认 20 秒超时过早失败。
- 新增 `StudioMediaLoading` 及 `assets/loading/video_loading.svg`；通过 flutter_svg 2.3.0 渲染（仅新增其必要依赖）。点阵使用局部 CustomPainter 重绘，SVG 静态子树缓存；支持减少动画与隐藏页面停用动画。
